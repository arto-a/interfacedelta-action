# Public branding audit

Human-visible product, CLI, Action, documentation, manifest, and release strings use InterfaceDelta. The following retained spellings are intentional canonical implementation terminology, not a competing public product brand:

- `AgentPassport`: the existing TypeScript type for the canonical Passport representation.
- `agent-passport.discovery-report`: the versioned canonical discovery-report discriminator.
- `agent-passport.schema.json` and its schema ID/title: the existing canonical schema artifact.
- Canonical core test descriptions that name the internal representation.

The runtime bundles retain only canonical machine identifiers from that list. Network identity, diagnostics, CLI output, Action output, and documentation use InterfaceDelta.
